# cIRCo.chat

**Всяка стая е различно шоу.** *Every room is a different show.*

Ретро чат стаи по градове и интереси, в духа на стария IRC.
Отвън: циркова табела със светлини и кръгла емблема за всяка стая.
Отвътре: чист IRC — час, `<ник>`, `***` влизания, `/команди`.

Живо: https://emillion-lab.github.io/CIRCO/

## Състояние — предварителна версия

- Един файл `index.html`. Без build, без библиотеки. Само шрифтовете идват от Google Fonts.
- Съобщенията се пазят в браузъра (localStorage) и изчезват след 24 часа.
- Отворени табове в един браузър се виждат помежду си (BroadcastChannel) — така се пробва „на живо“.
- **Истински сървър още няма.** Следва: Cloudflare Worker + Durable Object на стая (WebSocket).
  В кода транспортът е отделен (`Live`), сървърният трябва само да предложи същите методи.
- `#dating` и `#confessions` стоят на „Отваря скоро“, докато няма модерация.
  Отварят се с `open: true` в `ROOMS`.

## Команди в стаята

| Команда | Какво прави |
|---|---|
| `/nick име` | смяна на ника |
| `/me текст` | действие, в лилаво |
| `/join #стая` | отиваш в друга стая |
| `/part` | обратно към всички стаи |
| `/topic` | темата на стаята |
| `/clear` | чисти екрана |

`Tab` допълва ник, `↑`/`↓` връщат изпратените редове.
Адресът `…/CIRCO/#sofia` отваря направо стаята.

## Дизайн

- **Rye** — само логото и имената на стаите (латиница). **Anonymous Pro** — всичко останало, с кирилица.
- Цветовете на никовете са палитрата на mIRC, донастроена за тъмен фон.
- Емблемите са SVG в самия код, всяка с венец от лампички. Светнат венец = в стаята има хора.
- Табелата: лампичките се смятат по размера ѝ, всяка трета угасва и празнината тича по часовника.
  При `prefers-reduced-motion` всичко стои неподвижно.
